# Швейное производство — Supabase pilot

Отдельная тестовая публикация. Рабочая Google Apps Script версия находится в основном репозитории и этим сайтом не изменяется.

- Backend: Supabase pilot
- Доступ: только через Supabase Auth
- Прямые записи в таблицы запрещены RLS; изменения выполняются защищёнными RPC-функциями.
- `service_role` и другие административные секреты во frontend отсутствуют.
